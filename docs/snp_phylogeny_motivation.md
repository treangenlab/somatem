# SNP Phylogeny Motivation

This subworkflow was motivated by older reference-based bacterial SNP phylogeny workflows such as PHaME, but is implemented as a native Somatem/Nextflow workflow with current tool modules and Somatem-style launcher integration.

Parsnp/Harvest is included as the core-genome SNP alignment engine because it is directly applicable to bacterial whole-genome comparison and comes from the Harvest work associated with TreangenLab research.
